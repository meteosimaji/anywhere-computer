# Anywhere Computer 0.1.0a9

Anyone can download and use this public alpha release under the MIT license.
This is an alpha release, not a stable release. Automatic stable updates do not
select alpha tags; install this version manually.

## Downloads

Choose the portable ZIP for your OS/CPU. Each contains Python and pinned
runtime dependencies; extract the entire `Anywhere Computer` directory.

- macOS Apple Silicon: `anywhere-computer-0.1.0a9-macos-arm64.zip`
- Windows x64: `anywhere-computer-0.1.0a9-windows-x86_64.zip` (also tested under Windows ARM64 x64 emulation)
- Linux x64: `anywhere-computer-0.1.0a9-linux-x86_64.zip`
- Codex Plugin: `anywhere-computer-plugin-0.1.0-alpha.9.zip` (requires uv)
- `SHA256SUMS` records the release asset hashes.

No Intel macOS or Linux ARM64 portable asset is included in this release.
Source archives alone do not include Python. macOS/Linux use `./anywhere`;
Windows uses `anywhere.cmd`. Run `start`, then `status`, and configure an MCP
client with the `mcp` command. ChatGPT additionally needs an authenticated
public HTTPS MCP endpoint; see the README setup guide.

## Changes

- Explicit Mac/Windows device selection from one authenticated ChatGPT connection.
- Durable operation recovery and stateful Plugin/MCP sessions without invoking a Codex model.
- Skill body and supporting-resource resolution using the returned Skill directory.
- Typed Peekaboo GUI observation, element clicking, input and keys on macOS.
- Fix MCP capacity leaks after spawn rejection, terminal admission races, uncertain
  input delivery classification, and surviving-child ownership/update blocking.
- Windows owner-pipe connectivity and current-user local startup helper.
- Source/Plugin consistency checks, portable runtime verification and GitHub provenance.

## Validation and limits

The release commit must pass Quality CI on macOS, Windows and Ubuntu before
publication. Portable archives come unchanged from that commit's successful CI
and retain their GitHub build attestations. See the release evidence asset for
commit, workflow and artifact hashes.

Real GPT-5.6 Sol medium ChatGPT acceptance covered Mac/Windows selection,
Windows files/search/terminal, Skills, node_repl 40→42, recovery and cleanup.
A separate authenticated HTTP GUI test observed Calculator 42→50→51→52→53→54.
These checks do not guarantee every external Plugin, Windows native GUI,
Codex-owned Computer Use contexts, OS-restart process restoration, or every
user's login/sleep environment. GUI requires a separately installed compatible
Peekaboo and OS permissions. This release has no OS signing/notarization or GUI
installer. Linux agents require a usable unlocked credential store.

For upgrades, preserve the existing state directory, finish active work, and
run the new installation's `start` against that same directory. Update service
registrations as documented. Compare actual `computer_status` runtime/instance
identities at both ChatGPT and Codex entry points. Keep selected installation
folders; do not roll back operation databases. Automatic updates are optional
and disabled by default. No per-operation approval UI is added by this Plugin.
