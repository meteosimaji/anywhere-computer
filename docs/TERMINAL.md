# 端末出力の取得

`terminal_start` が返した `session_id` を `terminal_output` に渡す。
`cursor` は既定0で、出力先頭からの byte 位置。返された `next_cursor` を次の取得に使う。
負の値は呼出し時点の出力末尾を基準にする。たとえば `cursor: -4096` は末尾4096 byteから取得する。
`limit` は既定16000、最大100000 byteで、末尾指定でも適用される。
返される `next_cursor` は常に絶対位置なので、追加出力の続き取得に利用できる。

末尾より大きい負の指定は、保持されている先頭までに切り詰める。
セッションの保持上限は8 MiBで、破棄済み範囲を要求した場合は `dropped_bytes` に欠落量を返す。
出力開始以前の存在しない範囲は欠落量に数えない。
byte境界がUTF-8文字の途中に当たると置換文字で表示する。行単位のtailとは異なる。

現在の端末は stdin/stdout の PIPE 方式で、PTY やプロンプト自動認識は未実装。
