# 操作履歴の絞り込み

`operations_recent` は最新の操作要約を返す。`limit` は既定30、最大200。
`tool_name` はツール名の完全一致、`since` は開始時刻の下限（Unix 秒、小数可）で、
どちらも省略可能。下限時刻と同時刻の操作も含む。フィルターを適用してから件数を制限する。
結果は開始時刻の降順、同時刻なら operation ID の降順。

返却するのは operation_id/tool/started/state のみ。引数・パス・ファイル内容・結果本文は
履歴一覧に含めない。既知の operation_id の結果確認には `operations_get` を使う。
開始時刻による検索であり、完了時刻や実行時間の統計ではない。

例: `{"tool_name":"files_write","since":1788900000,"limit":20}`。
存在しないツール名への検索は空配列。過去の名称も検索できるよう、現在の登録一覧への存在を要求しない。
