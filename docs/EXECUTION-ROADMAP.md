# 独立した実行基盤の実装記録

2026-09-12: 添付の5段階すべてを継続実装する依頼。Python engine と既存の
未コミット監査修正を維持し、Codex互換はGUIの必須条件にしない。
以下は受け入れ管理であり、チェックのない項目を完成扱いしない。

製品方針（2026-09-12、ユーザーの最新指定）: 操作の許可はChat側の設定に従う。
Anywhere Computer独自の作業範囲承認画面や操作ごとの確認は設けない。
接続認証とOSが必要とする権限設定は初期セットアップにまとめ、設定の簡単さと
Codexでできる作業を通常Chatから実行できることを優先する。外部サービスが
要求する追加入力は同じ操作へ返せるようにするが、独自の承認を重ねない。

更新方針（監査後のユーザー指定）: 初回設定後、stableの検証済み配布物を
待機中に自動適用する。実作業中は待ち、適用ごとの独自確認は設けない。
ChatとCodexは共通エンジンを使用する。まず単一エンジンのidle更新を通し、
長時間セッションを保持する複数ワーカーへの拡張は後段で扱う。
監査A1–A4とCIを先に修正し、版情報の一元化、GitHub取得、共通エンジン切替、
両クライアントの受け入れ、独立GUIの配布統合の順で進める。
