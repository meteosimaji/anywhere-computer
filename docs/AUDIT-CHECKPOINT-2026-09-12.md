# 監査用の中間チェックポイント

ユーザーの依頼で2026-09-12に実装を区切り、現在のソース・テスト・同梱wheelを
GitHubへ保存する。5段階全体の完成、常駐版への適用、GUI機能の提供完了を示さない。
着手時の基準はmainのc074946707a7e127eda69cae547386a66213e56b。

## 方針

- Chat側の操作許可を使い、Anywhere Computer独自の作業承認画面・毎回確認を作らない。
- 設定を簡単にし、Chatが判断した操作をPluginが実行する。Codexの追加推論を必須にしない。
- 小さい変更ごとに小さい再現試験を行う。全件試験はこのような区切りで行う。
- 共通基盤や抽象化を先行させず、実際の操作経路を実装して検証する。

## 独立性・効率の現状

Python Engine、ファイル、端末、台帳はCodex実行ファイルなしでも動く。
test_codex_independence.pyは存在しないCodexパスでPlugin接続が失敗した後も、
ファイル作成・読取・操作回収・実端末が正常に動くことを確認する。

codex_*の会話/スキル取得とPlugin中継はCodex App Serverに依存する。
検証済みCodexは0.154.0-alpha.6.2であり、将来版の内部API互換は保証できない。
独立ブラウザーと直接MCPを基本経路にし、Codex互換を任意の補助経路にする作業が残る。

トークン効率はCodexとの同条件比較をまだ行っていない。ページ取得・セッション保持・
選択したツールの詳細取得はあるが、呼出し前カタログ再取得、全ツールのスキーマ公開、
結果のtext/structuredContent両方への格納がある。通信byte量とモデルの課金token量は別物。
キャッシュ、必要な観測だけを返すブラウザー契約、比較測定は未完了。
