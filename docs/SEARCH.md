# ファイル検索

`search_start` で検索を開始し、返された `search_id` を `search_results` に渡して
ページ取得します。実行中にも取得でき、`search_stop` で中断できます。
IDはエージェントのメモリに属し、エージェント再起動後は使えません。

```json
{
  "path": "/absolute/project",
  "kind": "text",
  "pattern": "initialize",
  "filename_glob": "*.py",
  "excluded_directories": [".git", "node_modules", "build*"],
  "whole_word": true,
  "ignore_case": true,
  "max_files": 10000,
  "max_depth": 32,
  "max_results": 1000
}
```

- `kind` は名前検索の `names` またはUTF-8本文検索の `text` です。
- `mode` は既定 `literal`。`regex` を明示すると Python 標準 re の正規表現で照合します。
  メタ文字の有無からモードを推測しません。regex の大小文字無視は re.IGNORECASE で、
  literal の Unicode casefold と完全に同じではありません。
- `filename_glob` は各ファイルの名前だけに適用します。`*`、`?`、`[abc]` のような
  標準ライブラリfnmatchのパターンです。相対パスや `**` の再帰構文、波括弧展開ではありません。
- `excluded_directories` は各ディレクトリ名に適用するglobの配列です。最大32個です。
- `ignore_case` は検索文字列と両方のglobにも適用し、Unicode casefoldを使います。
- `whole_word` は一致の直前・直後が英数字を含むUnicode alphanumericまたは `_` でないことを
  要求します。日本語の形態素解析や自然言語の単語区切りではありません。
- 隠しファイル・ディレクトリは既定で除外し、`include_hidden` で含められます。
  シンボリックリンクは探索対象から除外します。ただし外部プロセスの同時置換に対する隔離機構ではありません。

探索上限は既定で10000ファイル、深さ32、結果1000件です。最大値はそれぞれ100000、128、10000です。
`max_depth: 0` はルートディレクトリ直下だけです。列挙したファイルは、隠しファイルやglobで
除外したものも `visited_files` に含め、探索量の上限に数えます。

結果の `truncated` と `limit_reason` に上限到達を表示します。reasonは `max_files`、
`max_depth`、`max_results`、`timeout` のいずれかです。複数の上限に当たった場合は最後に記録した理由です。
上限到達時は、残りの対象に一致があるかどうかにかかわらずtruncatedを表示します。
`skipped` は読み取り不可・非UTF-8・サイズ超過・通常ファイル以外を読み飛ばした数、
`directory_errors` は列挙できなかったディレクトリのエラー数です。
`completed` は探索処理が終了した意味で、truncated/skipped/errorsがゼロである保証ではありません。

本文読み取りは実際に取得するバイト数を16 MiBに制限します。読み取り前のサイズだけでは
判定せず、途中で増大しても上限を超えて読み続けません。FIFOなどは待機せずに拒否します。
UTF-8全体を確認してから行を照合するため、ファイル先頭に一致があっても全体の上限付き読み取りは行います。
一致行の表示は先頭2000文字までです。1行に複数一致しても結果は1行分です。

`context_lines` は既定0、最大10で、本文検索の一致行の前後にそれぞれ指定数の行を付けます。
`before`/`after` は行番号と文字列の配列です。各文脈行も2000文字までで、ファイル端では
存在する行だけ返します。重なった文脈は各一致行に付け、文脈行を一致件数には数えません。
ページは要求件数以内かつ結果の JSON 約512 KBを上限に分割し、実際に返した件数に応じた
`next_cursor` から継続します。名前検索では文脈行を付けません。

中断は協調的で、ワーカーは各行の間に中断状態を確認します。OS側で進行中のファイル読み取りを
強制中断する保証はありません。ディレクトリ列挙の一部は同期処理なので、応答しないネットワーク
ファイルシステムに対する強制タイムアウトは未実装です。Office内容検索も未実装です。

`timeout_ms` は既定30000、1〜600000ミリ秒で、検索タスクの実行時間に上限を設けます。
上限到達時は取得済み結果を保持し、`state: completed`、`truncated: true`、
`limit_reason: timeout` を返します。手動停止の `cancelled` とは区別します。
実行中ワーカーにも中断フラグを伝えますが、同期OS呼出しを強制終了する機能ではありません。

正規表現の照合は独立Pythonプロセスで行い、検索停止や期限切れで子を終了・回収します。
現段階はファイル（名前検索では名前）ごとにプロセスを起動するため、大量ファイルでの
性能検証・最適化は未完了です。本文は行ごとに照合し、複数行をまたぐ一致は扱いません。
whole_word は一致範囲の前後が英数字/underscoreでないことを検査します。
結果の累積 JSON 容量は16 MiBを上限にし、超過時は既存結果を残したまま
`limit_reason: output_bytes` で打ち切ります。これはPython全体のメモリ使用量の上限ではありません。
