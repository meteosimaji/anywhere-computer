# Security policy

## Supported versions

Security fixes are developed for the current `main` branch and the latest published
beta release. Older alpha builds and historical releases are not maintained.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/meteosimaji/anywhere-computer/security/advisories/new) for suspected vulnerabilities. Please avoid public issues for reports involving credentials, OAuth tokens, remote terminal access, or private user data. Include the affected version, a concise reproduction, impact, and any relevant logs with secrets removed.

The maintainers will acknowledge a report, investigate its impact, and coordinate a fix and disclosure with the reporter. There is no guaranteed response or remediation deadline. For ordinary bugs and feature requests, use the public issue tracker.
